Prompt Contribution Graph v0.3.1 updates desktop dependencies. Application behavior is unchanged from v0.3.0.

## Updates

- Tauri 2.12.1, Tauri CLI 2.12.0, and tauri-build 2.7.1
- tauri-plugin-opener 2.7.0 and tauri-plugin-single-instance 2.5.2
- uuid 1.26.1, base64 0.23.1, and rusqlite 0.40.2
- GitHub Actions download-artifact v8

## Known limitations

- The macOS build is ad-hoc signed and not Apple-notarized, so macOS may display a Gatekeeper warning.
- Windows, iPhone, and iPad builds are not included.
